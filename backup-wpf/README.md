# Claude Quota

A tiny always-on-top Windows widget that shows how much of your Claude usage is left: the 5-hour
session limit, the weekly limit, and extra-usage credits.

It sits as a translucent "soap bubble" pill docked to a screen edge. Hover it to see details.

## Features

- **Always on top.** Stays above other windows and is hidden from the taskbar and Alt+Tab.
- **Collapsed pill.** Shows session % · week % and four status squares:

  | Square | Meaning |
  |---|---|
  | Orange | Session (5h) left. Fills from the bottom. |
  | Purple | Week (7d) left |
  | Red | Extra-usage spend vs. monthly cap. Stays empty when no cap is set. |
  | Blue | Lit when the last update succeeded, dark on error |

- **Hover to expand.** Shows Session/Week rings with reset countdowns, extra-usage spend and the
  last update time.
- **Drag to any edge.** The widget snaps to the nearest edge of the monitor you drop it on.
  - Top/bottom edges: a horizontal pill (280×36).
  - Left/right edges: a vertical strip (40×150) that expands into a tall panel along the edge.
- **Multi-monitor and mixed DPI.** It works on any monitor and stays crisp at any scaling. The
  monitor, edge and position are remembered. If that monitor is gone, it moves to the primary one.
- **Auto refresh.** Updates every 60 seconds. Right-click for **Refresh now**,
  **Start with Windows** and **Exit**.
- **Click-through.** Everything around the pill passes mouse clicks to the windows underneath.

## Requirements

- Windows 10/11, x64.
- **Claude Code installed and signed in** with a Claude subscription. The widget reads the OAuth token
  that Claude Code stores in `%USERPROFILE%\.claude\.credentials.json`. It never writes or sends the
  token anywhere except to Anthropic's usage endpoint.

## Install

1. Run `dist\ClaudeQuota-Setup.msi`. No admin rights are needed.
   - It installs per-user to `%LocalAppData%\Programs\Claude Quota`.
   - It adds a Start-menu shortcut, enables *Start with Windows*, and launches the widget.
2. The installer is unsigned. If SmartScreen warns, choose **More info → Run anyway**.

To uninstall, use **Settings → Apps → Installed apps → Claude Quota → Uninstall**. This closes the
widget and removes the files, the shortcut and the autostart entry.

## Usage

| Action | How |
|---|---|
| See details | Hover the pill |
| Move | Drag it and release near any edge of any monitor |
| Refresh / autostart / quit | Right-click the pill |

The position is saved in `%AppData%\ClaudeQuota\dock.txt` as `monitor|edge|fraction`. Delete that
file to reset to the top-right corner of the primary monitor.

## Build from source

Requires the **.NET 10 SDK**. WiX is restored from NuGet automatically, so nothing else needs
installing.

```powershell
# Run locally (framework-dependent build)
dotnet run -c Release

# Build the installer -> dist\ClaudeQuota-Setup.msi
.\build-installer.ps1 -Version 1.0.1
```

Bump `-Version` for every release. MSI upgrades only replace an installed copy when the version is
higher.

`build-installer.ps1` does two things:
1. Publishes a self-contained, compressed single-file `ClaudeQuota.exe` to `publish\`, so the target
   PC needs no .NET runtime.
2. Packages it with WiX (`installer\`) into `dist\ClaudeQuota-Setup.msi`.

`installer\make-icon.ps1` regenerates `app.ico`. The build runs it only if the icon is missing.

## Troubleshooting

| Symptom | Fix |
|---|---|
| "Login expired - run Claude Code once." | Open Claude Code so it refreshes its token. The widget re-reads the file every minute. |
| Shows `…` / "Loading…" for a long time | Usually a network problem. The status line in the expanded view shows the error. |
| Widget is off-screen or on the wrong monitor | Delete `%AppData%\ClaudeQuota\dock.txt` and restart. |
| Text hard to read over busy backgrounds | Increase the tint in `MainWindow.xaml` (`Pill` → `Background="#50000000"`). |

## Note on the data source

Usage comes from `GET https://api.anthropic.com/api/oauth/usage`, the endpoint Claude Code itself
uses. It is undocumented and may change without notice.
